# Disease Prediction

A Machine Learning based Disease Prediction system that predicts the presence of disease based on common symptoms.

## Project Overview

This project uses patient symptoms as input and applies a Random Forest Classifier to predict whether disease is detected.

## Symptoms Used

- Fever
- Cough
- Fatigue
- Headache
- Body Pain
- Sore Throat
- Breathing Problem

## Machine Learning Model

- Random Forest Classifier

## Machine Learning Workflow

1. Create and prepare the dataset
2. Analyze symptom distribution
3. Split data into training and testing sets
4. Scale the features
5. Train Random Forest model
6. Evaluate model performance
7. Generate classification report
8. Generate confusion matrix
9. Analyze feature importance
10. Predict disease for a new patient

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
